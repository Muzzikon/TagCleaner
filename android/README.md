# TagCleaner для Android

**[Скачать APK 1.0.0](https://github.com/Muzzikon/TagCleaner/releases/download/android-v1.0.0/TagCleaner-Android-1.0.0.apk)** · [Релиз и контрольные суммы](https://github.com/Muzzikon/TagCleaner/releases/tag/android-v1.0.0)

Android-версия открывает папки и отдельные аудиофайлы через системный выбор файлов. На узком экране список и карточка трека открываются по очереди. От ширины **720 dp** список и редактор видны рядом. Экран можно поворачивать и изменять размер окна в режиме разделённого экрана.

Поддерживаются **Android 7.0 и новее** на **ARM64** и **x86-64**, а также MP3, FLAC, M4A/MP4, Ogg/Opus, WAV и AIFF. Локальные операции работают офлайн.

## Работа с библиотекой

1. Выберите папку или несколько файлов. Папки сканируются вместе с подпапками. Треки упорядочены по времени изменения, сначала новые.
2. Откройте трек. На вкладке **«Теги»** можно вручную заполнить поля, взять исполнителя и название из имени файла и очистить текст перед сохранением.
3. На вкладке **«Обложка»** выберите JPEG или PNG либо запустите поиск по MusicBrainz и Cover Art Archive. Поиск сверяет исполнителя, название и длительность записи и показывает обложки конкретных изданий. Выберите подходящую картинку и вшейте её отдельно либо примените всю очередь текущей библиотеки. Сетевой поиск передаёт исполнителя, название и интервал длительности в MusicBrainz. Аудио остаётся на устройстве.
4. Используйте **«Разделы»**, чтобы увидеть треки с обложками, необработанные, очередь, ошибки и результаты поиска без подходящей обложки.

Перед записью на месте TagCleaner сохраняет последнюю версию оригинала во внутреннем хранилище приложения, проверяет результат и восстанавливает время изменения, если это разрешено. Когда хранилище запрещает восстановление даты, можно сохранить отдельную копию или явно разрешить новую дату для исходного трека. По умолчанию исходный файл остаётся без изменений. Некоторые облачные поставщики открывают треки только как потоки и требуют сначала скачать их на устройство.

**«Восстановить оригинал»** доступно в карточке трека с резервной копией. В меню **«Резервные копии»** можно проверить занимаемое место и освободить его. Копии хранятся в данных приложения и удаляются вместе с ними.

В этой версии доступны ручное редактирование, локальная очистка и поиск обложек в MusicBrainz. Распознавание по аудио, дополнительные каталоги Windows, увеличение обложек и перенос файлов по папкам пока доступны в Windows-версии. Разделы Android фильтруют треки внутри библиотеки.

## Сборка

Нужны Android Studio или Android SDK с платформой API 37, JDK 17+ и Python 3.14 для сборки Chaquopy. Проект можно открыть в Android Studio из папки `android`. Если `python3.14` недоступен в `PATH`, задайте `TAGCLEANER_BUILD_PYTHON` с абсолютным путём к Python 3.14. На Windows плагин также ищет `py -3.14`.

```powershell
cd android
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

На Linux/macOS выполните `sh ./gradlew :app:assembleDebug :app:lintDebug` из папки `android`. APK для установки находится в `app/build/outputs/apk/debug/app-debug.apk`. Для релизной сборки доступны задачи `:app:assembleRelease` и `:app:bundleRelease`. Релиз требует своей подписи.

Интерфейс и доступ к документам написаны на Java. Gradle включает в APK общие модули доступа к тегам, обложкам и очистки из корневой папки `core`, а Chaquopy поставляет Python и Mutagen. [Сторонние компоненты](../THIRD-PARTY.md)

Для проверки записи и резервных копий установите Mutagen той же версии, что и в `app/build.gradle`, затем запустите из корня репозитория `python -m unittest discover -s android/tests`. На Windows тесты с `futimens` пропускаются, поскольку Python поддерживает смену времени по дескриптору на Unix.
