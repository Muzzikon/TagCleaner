# Работа с TagCleaner

## Открыть музыку

1. Скачайте и распакуйте архив по [инструкции на главной](../README.md#первый-запуск). Запустите `TagCleaner.cmd`.
2. Слева нажмите **«Выбрать папку»**, чтобы открыть папку с музыкой, или **«Файлы»**, чтобы выбрать отдельные треки. **«Прошлый набор»** открывает последний сохранённый список. F5 перечитывает папку и теги.
3. Найдите трек по артисту, названию или имени файла в поле над таблицей. Клик по строке открывает панель справа. Галочки выделяют треки для пакетных действий. Shift + клик выделяет диапазон, Ctrl + клик — отдельные строки.

## Исправить теги

1. В разделе **«В работе»** выберите режим **«Продолжить проверку»** и нажмите **«Начать сканирование»**. Программа проверит локальные теги и попробует найти данные в каталогах. Для поиска нужен интернет.
2. Нажмите на трек, чтобы сравнить текущие и предложенные значения. Карандаш открывает редактор, где можно задать значения вручную и выбрать нужное издание. Сверяйте версию трека, особенно для ремиксов и концертных записей.
3. Выделите треки, нажмите **«Посмотреть изменения»** и проверьте список полей. Подтвердите запись в окне предпросмотра. **«Подтвердить текущие теги»** подходит, если имеющиеся значения вас устраивают.

## Подобрать и вшить обложки

1. Слева откройте **«Без обложки»** для файлов без картинки или **«Исходные обложки»** для замены существующих. Кликните по треку, затем справа нажмите **«Найти обложки»** или **«Обновить варианты»**. Для нескольких треков выделите строки и нажмите **«Обновить варианты»** под таблицей. Блок **«Загрузить варианты обложек»** позволяет подготовить целый раздел.
2. Выберите вариант и сравните его с изображением **«Сейчас в файле»**. Если каталог показывает расхождения, проверьте издание и поставьте галочку ручного выбора. Через **«Свой файл»** можно добавить JPEG или PNG. Через **«Вставить скриншот»** можно загрузить изображение из буфера. Через **«Добавить по ссылке»** можно получить картинку со страницы поддерживаемого сервиса.
3. Нажмите **«В очередь»**. Для уже встроенной картинки можно выбрать **«Встроенную в очередь»**. Галочка **«После добавления в очередь — следующий трек»** ускоряет просмотр списка.
4. Откройте **«Очередь обложек»** слева. Нажмите **«Выбрать все по фильтру»** или выделите несколько строк вручную, затем нажмите **«Вшить выбранные»**. После записи используйте **«Показать вшитые и подтверждённые»**, чтобы увидеть готовые треки. При ошибке конкретный трек остаётся в очереди для повтора.

**«Ручной поиск»** пригодится для треков, требующих отдельного внимания. Если найденных вариантов недостаточно, откройте **«Уточнить поиск»**, измените запрос и повторите поиск. Эти поля используются для поиска картинок.

## Вернуть исходный файл

Откройте **«Резервные копии»** вверху окна. Откроется папка `backups`, где копии разложены по времени записи. Закройте TagCleaner, проверьте имя и дату копии и при необходимости скопируйте её обратно в музыкальную папку. При следующем запуске нажмите F5, чтобы перечитать теги и обложку. Отчёты, журнал и сведения о размере кэша доступны из верхнего меню.
