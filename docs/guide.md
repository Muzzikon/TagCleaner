# Работа с TagCleaner

## Открыть музыку

1. Скачайте и распакуйте архив по [инструкции на главной](../README.md#первый-запуск). Запустите `TagCleaner.cmd`.
2. Слева нажмите **«Выбрать папку»**, чтобы открыть папку с музыкой, или **«Файлы»**, чтобы выбрать отдельные треки. **«Прошлый набор»** открывает последний сохранённый список. F5 перечитывает папку и теги.
3. Найдите трек по артисту, названию или имени файла в поле над таблицей. Клик по строке открывает панель справа. Галочки выделяют треки для пакетных действий. Shift + клик выделяет диапазон, Ctrl + клик — отдельные строки.

## Исправить теги

1. В разделе **«В работе»** выберите режим **«Продолжить проверку»** и нажмите **«Начать сканирование»**. Программа проверит локальные теги и попробует найти данные в каталогах. Для поиска нужен интернет.
2. Нажмите на трек, чтобы сравнить текущие и предложенные значения. Карандаш открывает редактор, где можно задать значения вручную и выбрать нужное издание. Сверяйте версию трека, особенно для ремиксов и концертных записей.
3. Выделите треки, нажмите **«Посмотреть изменения»** и проверьте список полей. Подтвердите запись в окне предпросмотра. **«Подтвердить текущие теги»** подходит, если имеющиеся значения вас устраивают.

Для проверки уже сохранённых тегов отметьте треки и нажмите **«Проверить теги выбранных»** под списком. После проверки нажмите **«Показать замечания»**, чтобы увидеть треки с расхождениями или ошибками чтения, и откройте нужную строку. TagCleaner использует правила оформления и сохранённые результаты поиска. Теги в файлах и статусы треков сохраняются.

## Подобрать и вшить обложки

1. Слева откройте **«Без обложки»** для файлов без картинки или **«Исходные обложки»** для замены существующих. Кликните по треку, затем справа нажмите **«Найти обложки»** или **«Обновить варианты»**. Чтобы обновить сразу несколько треков, выберите охват в блоке **«Варианты обложек»** и нажмите **«Обновить варианты»**. Та же кнопка под таблицей работает с отмеченными строками. TagCleaner проверит сохранённые картинки, попробует восстановить недостающие оригиналы и повторит поиск только для треков, которым это нужно. Кнопка **«Загрузить варианты»** позволяет подготовить новые варианты заранее.
2. Выберите вариант и сравните его с изображением **«Сейчас в файле»**. Если каталог показывает расхождения, проверьте издание и поставьте галочку ручного выбора. Через **«Свой файл»** можно добавить JPEG или PNG. Через **«Вставить скриншот»** можно загрузить изображение из буфера. Через **«Добавить по ссылке»** можно получить картинку со страницы поддерживаемого сервиса.
3. Нажмите **«В очередь»**. Для уже встроенной картинки можно выбрать **«Встроенную в очередь»**. Галочка **«После добавления в очередь — следующий трек»** ускоряет просмотр списка.
4. Откройте **«Очередь обложек»** слева. Нажмите **«Выбрать все по фильтру»** или выделите несколько строк вручную, затем нажмите **«Вшить выбранные»**. При ошибке конкретный трек остаётся в очереди для повтора.
5. Чтобы проверить результат, откройте **«Все обложки»** и выберите фильтр **«Вшитые TagCleaner»**. Клик по треку открывает оригинал из аудиофайла. В этом же разделе видны исходные и подтверждённые без замены обложки.

**«Ручной поиск»** пригодится для треков, требующих отдельного внимания. Если найденных вариантов недостаточно, откройте **«Уточнить поиск»**, измените запрос и повторите поиск. Эти поля используются для поиска картинок.

Обложки синглов и отдельных публикаций SoundCloud показываются выше обложек альбомов и EP. Если раньше TagCleaner сохранил только обложки релизов, массовое **«Обновить варианты»** дополнительно проверит SoundCloud. Выбор картинки из публикации требует ручного подтверждения соответствия.

Через **«Добавить по ссылке»** поддерживаются также подборки SoundCloud с адресом вида `soundcloud.com/автор/sets/название`. Их обложка добавляется с ручной проверкой соответствия конкретному треку и версии.

При сбое сервиса нажмите **«Повторить сбои»**. Повтор запрашивает только проблемные источники для треков в выбранном охвате. Итоги показывают отдельно отсутствие вариантов и недоступность источников. Ранее найденные варианты сохраняются. Отказы из-за неподдерживаемого формата или размера изображения остаются в **«Подробностях предупреждений»**. Для них можно выбрать другой вариант. При ограничении частоты запросов повторите позже, после паузы сервиса.

Во время паузы Deezer пакетный повтор откладывает треки, для которых остался только этот каталог. В итогах указано, когда повтор станет доступен.

По умолчанию **«Загрузить варианты»** пропускает готовые варианты, завершённый поиск без результата и треки, для которых доступен **«Повторить сбои»**. Для нового поиска по всему выбранному охвату снимите галочку и нажмите **«Заново найти варианты»**.

## Вернуть исходный файл

Откройте **«Резервные копии»** вверху окна. Откроется папка `backups`, где копии разложены по времени записи. Закройте TagCleaner, проверьте имя и дату копии и при необходимости скопируйте её обратно в музыкальную папку. При следующем запуске нажмите F5, чтобы перечитать теги и обложку. Отчёты, журнал и сведения о размере кэша доступны из верхнего меню.
