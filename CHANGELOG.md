# История изменений TagCleaner

## 2026.11.22.1 — поиск изданий по нескольким каталогам

- Поиск изданий использует ISRC из распознавания и учитывает введённое название сингла, альбома или EP. Найденные синглы и EP показываются перед сборниками, если название не было уточнено.
- Если доступны только сборники или поиск не дал результатов, TagCleaner проверяет издания на SoundCloud. Страницу издателя можно добавить по ссылке, а обложка найденного издания доступна при поиске обложек.
- Поиск изданий работает в фоне. Если связь трека с релизом требует проверки, редактор позволяет вручную перенести доступные данные издания.

## 2026.11.22 — сохранение времени изменения файлов

- Запись тегов, вшивание обложек, переименование и перенос сохраняют время изменения аудиофайла с исходной точностью. Это сохраняет порядок библиотеки при сортировке по дате.
- При откате восстанавливаются содержимое из резервной копии и время изменения, которое было у файла перед операцией. При чтении старой копии более поздняя дата файла сохраняется.
- При кратковременной блокировке Windows TagCleaner повторяет установку времени и проверяет результат перед завершением операции.

## 2026.11.21 — отдельные обложки треков и повтор поиска

- Поиск показывает обложки синглов и отдельных публикаций SoundCloud рядом с вариантами с альбомов и EP. Массовое обновление дополняет сохранённые подборки без повторного запроса к уже проверенным каталогам.
- Пакетный повтор откладывает оставшиеся запросы только к Deezer во время паузы этого каталога и продолжает проверку других источников. В итогах видны причина и время следующей попытки.

## 2026.11.20 — проверка тегов и работа с обложками

- Кнопка «Проверить теги выбранных» перечитывает сохранённые теги, сверяет оформление и показывает расхождения с уже найденными данными. Проверка не записывает теги и не переводит треки в «Исправленные».
- Поиск по библиотеке учитывает варианты пробелов и разделителей в исполнителе, названии и имени файла.
- Раздел «Все обложки» показывает текущие изображения в аудиофайлах. Фильтр «Вшитые TagCleaner» помогает проверить результат записи.
- Доступны массовое обновление вариантов и повтор только по источникам, которые не ответили. Программа сохраняет найденные ранее варианты и различает сетевые сбои и поиск без результата.
- Обложки подборок SoundCloud можно добавить по ссылке. Для маленьких изображений масштабирование использует LapSRN и восстановление деталей с Real-ESRGAN.
- Поиск изданий и обработка кредитов участников точнее учитывают версию трека и состав исполнителей.

## 2026.11.18 — добавление обложки одним нажатием

- Нажатие «В очередь» во время загрузки оригинала дожидается загрузки и завершает добавление автоматически, включая обновлённые изображения источника. Повторный клик больше не требуется.

## 2026.11.17 — техническая ревизия

- Исправлен выбор обложки, оригинал которой исчез из кэша и изменился на сервере: при выборе загружается актуальная картинка, а очередь сохраняет показанные байты. Уже сохранённые в очереди изображения сохраняют строгую проверку оригинала.

- Независимые оригиналы обложек загружаются параллельно; запросы к одному оригиналу по-прежнему объединяются.
- При повреждённом изображении поиск пробует запасные размеры того же источника и сохраняет фактически загруженный оригинал.
- Ошибка отдельного релиза Discogs больше не обрывает проверку остальных релизов. Удалённый релиз не вызывает паузу всего каталога.
- При выходе из пакетной операции фоновые поиски получают сигнал остановки.
- Чтение кэша устойчиво к одновременной очистке и замене файлов. Настройки и последний список файлов записываются атомарно; некорректная структура JSON не ломает загрузку.
- Отказ записи необязательного кэша Discogs/Last.fm больше не теряет полученные результаты поиска.
- Исправлены счётчик сохранённых вариантов, описание лимита кэша и обработка некорректного времени ожидания от каталога.

## 2026.11.8

- Добавление обложки в очередь использует оригинал, загруженный для предпросмотра. TagCleaner проверяет контрольную сумму и сохраняет точное изображение для пакетного вшивания.
- Для предпросмотра TagCleaner сначала проверяет кэш, очередь и обложку внутри аудиофайла. Одновременные запросы за одним оригиналом к одному источнику объединяются.
- Пока источник загружает оригинал, можно переключаться между треками. При сбое кнопка **«Повторить добавление»** повторяет загрузку выбранного изображения.
- Список обновляет только изменившиеся строки при работе с очередью. Ошибка добавления отображается в интерфейсе, после чего действие можно повторить.
- Лимит кэша оригиналов увеличен до 1 ГиБ. При очистке дольше сохраняются недавно открытые картинки.
- Улучшено сопоставление обложек для треков, у которых участники указаны через косую черту и подтверждаются данными каталога.

## 2026.11.7

- Первый публичный релиз для Windows x64 с редактированием тегов, подбором обложек и пакетным вшиванием через очередь.
