# История изменений TagCleaner

## 2026.11.8

- Добавление обложки в очередь использует оригинал, загруженный для предпросмотра. TagCleaner проверяет контрольную сумму и сохраняет точное изображение для пакетного вшивания.
- Для предпросмотра TagCleaner сначала проверяет кэш, очередь и обложку внутри аудиофайла. Одновременные запросы за одним оригиналом к одному источнику объединяются.
- Пока источник загружает оригинал, можно переключаться между треками. При сбое кнопка **«Повторить добавление»** повторяет загрузку выбранного изображения.
- Список обновляет только изменившиеся строки при работе с очередью. Ошибка добавления отображается в интерфейсе, после чего действие можно повторить.
- Лимит кэша оригиналов увеличен до 1 ГиБ. При очистке дольше сохраняются недавно открытые картинки.
- Улучшено сопоставление обложек для треков, у которых участники указаны через косую черту и подтверждаются данными каталога.

## 2026.11.7

- Первый публичный релиз для Windows x64 с редактированием тегов, подбором обложек и пакетным вшиванием через очередь.
