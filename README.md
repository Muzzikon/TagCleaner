# TagCleaner

TagCleaner помогает привести в порядок музыкальную библиотеку на Windows. Можно править теги, подбирать обложки из каталогов и вшивать выбранные изображения в несколько треков за один раз.

## Первый запуск

1. Скачайте `TagCleaner-Windows-x64.zip` и распакуйте всю папку туда, где у вас есть права на запись, например в «Документы».
2. Запустите **TagCleaner.cmd**. При первом запуске он скачает Python 3.12, библиотеки, FFmpeg и Chromaprint. Понадобится интернет, несколько минут и около 1 ГБ свободного места. Установка выполняется внутри папки приложения.
3. В TagCleaner нажмите **«Выбрать папку»** или **«Файлы»**. Для первого знакомства можно взять копии нескольких треков.

Сборка рассчитана на Windows 10/11 x64. Для окна приложения используется [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/). Можно также открыть интерфейс в обычном браузере через `TagCleaner.cmd --browser`.

## Теги и обложки

- **Теги.** Нажмите **«Начать сканирование»**, проверьте предложения и откройте **«Посмотреть изменения»** перед записью. Можно править теги вручную.
- **Обложки.** Выберите трек, найдите варианты или добавьте свою картинку и нажмите **«В очередь»**. В разделе **«Очередь обложек»** отметьте нужные треки и нажмите **«Вшить выбранные»**. Неудачные записи можно повторить.
- **Резервные копии.** Перед записью приложение сохраняет оригинал. Копии доступны из меню **«Резервные копии»** и в папке `backups`.

Программа открывает MP3, FLAC, M4A/MP4, Ogg/Opus, WAV и AIFF. Ручное редактирование и работа с локальными картинками доступны без сети после установки. Онлайн-поиск обращается к внешним каталогам. В зависимости от операции сервисы получают данные запроса, аудиоотпечаток или фрагмент аудио для распознавания. Сторонние сервисы могут ограничивать запросы или временно не отвечать.

## Если что-то не работает

- **Первый запуск прервался.** Запустите `TagCleaner.cmd` повторно. Готовые компоненты используются снова. Для скачивания нужны GitHub, PyPI, серверы Astral и зеркало FFmpeg. Если не загрузились только аудиоинструменты, можно работать с тегами и обложками, а для повтора установки выполнить `TagCleaner.cmd --setup-only`.
- **Окно приложения не открывается.** Установите [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) или запустите `TagCleaner.cmd --browser` из папки приложения. Подробности ошибки запуска окна сохраняются в `desktop_error.txt`.
- **Обновление.** Распакуйте новую версию в отдельную папку. Чтобы перенести настройки, очередь и историю, закройте обе версии и скопируйте `config` и `ui_runtime` из старой. При необходимости сохраните отдельно `backups` и `cache`.
- **Отчёт об ошибке.** Укажите версию релиза, версию Windows и шаги для повторения. Уберите из журнала личные пути, ключи и имена файлов, которые не хотите публиковать.

Для запуска из исходников установите [uv](https://docs.astral.sh/uv/getting-started/installation/), добавьте его в `PATH` и запустите `TagCleaner.cmd` из корня проекта. Состав сторонних компонентов описан в [THIRD-PARTY.md](THIRD-PARTY.md).
